# Release files

`apolkosnik.3DO/` is the complete core directory to copy to `/cores/apolkosnik.3DO/` on the
microSD card (add `bios.bin`, see the top-level README). Built with Vivado 2018.3 via
`tools/build_vivado2018.sh`; timing met (WNS +0.37 ns), 35% LUTs, 88% block RAM.

This is a hardware bring-up build: not yet tested on a Game Bub, and discs are limited to
22 MiB (see the top-level README).
